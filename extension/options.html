Gemini API key

@me uses Google's Gemini to read syllabi, write quizzes, and understand chat. It's free: in Google AI Studio, click Get API key, then Create API key. No credit card needed. On the free tier, Google may use what you send to improve its products.

Test connection loads the models your key can use. Stick with a Flash model, since those are on the free tier.

Google Calendar

@me reads when you're busy and puts study sessions on its own "@me Study" calendar, so your main calendar stays untouched.

Canvas

In Canvas, go to Account, Settings, and click New Access Token. Set an expiration date so it can't live forever.
